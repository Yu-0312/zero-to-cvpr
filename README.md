# 從零到 CVPR · 互動式學習路線 🏔️

一條為**零基礎學習者**設計的互動式學習路線：從數學與程式起步，一路走到能獨立完成研究並投稿 CVPR。

**線上版（GitHub Pages）：** `https://<你的用戶名>.github.io/zero-to-cvpr/`

## 這是什麼

不是又一份「書單合集」，而是一條**可執行、可勾選、可衡量**的路線：

- **8 個階段**（P0–P7），每個階段有明確的通關標準（里程碑），做到才算過關
- **60+ 個可勾選的任務**，進度自動保存在瀏覽器本地，隨時回來繼續
- **18 道隨堂小測驗**，即時判斷對錯並附解析，檢驗你是否真的懂了
- **真實的時間線規劃**：從 2026 年 9 月出發，全職節奏約 14 個月，對齊 CVPR 2028（預計 2027 年 11 月截稿）；兼職節奏對齊 CVPR 2029
- **算力指南、常見陷阱、FAQ**：沒有 GPU 也能開始，少走大多數人踩過的坑

## 路線總覽

| 階段 | 主題 | 全職時長 | 關鍵里程碑 |
|------|------|----------|------------|
| P0 | 認識戰場 | 1 週 | 翻 5 篇論文的「殼」，選定 2 個候選方向 |
| P1 | 數學與程式基礎 | 約 2 個月 | 純 NumPy 實作線性迴歸與 k-means |
| P2 | 深度學習基礎 | 約 2.5 個月 | CIFAR-10 上 90%+，手寫 ResNet-18 |
| P3 | 電腦視覺核心 | 約 2.5 個月 | 跑通偵測／分割／擴散／3DGS pipeline |
| P4 | 讀論文與復現 | 約 1.5 個月 | 30+ 篇四欄式筆記，完整復現一篇論文 |
| P5 | 找到研究問題 | 約 1.5 個月 | 一頁 proposal＋第一個 baseline |
| P6 | 做出成果與寫作 | 約 2.5 個月 | Figure 1＋主表＋全文初稿 v1 |
| P7 | 打磨、投稿與 Rebuttal | 約 1.5 個月 | 提前 48 小時提交（被拒也有 B 計畫） |

## 如何使用

1. **線上使用**：打開 GitHub Pages 連結，從 P0 開始逐階段勾選
2. **本地使用**：直接雙擊 `index.html`，或在本目錄起一個靜態伺服器：
   ```bash
   python3 -m http.server 8080
   # 瀏覽器打開 http://localhost:8080
   ```
3. **配合自己的學習倉庫**：建議把這個專案 fork 或 clone 下來，P1 開始就在旁邊建自己的筆記倉庫、每週 commit——這本身就是 P1 的里程碑之一

## 隱私說明

所有勾選進度與深色模式偏好僅保存在**你自己的瀏覽器**（localStorage），不上傳任何資料。
